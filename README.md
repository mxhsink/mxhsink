### 🏀 [NBA Fantasy Predictor](https://github.com/mxhsink/NBA-Fantasy-Predictor)

Predicts each NBA player's stats for their **next game**, then turns them into **ESPN fantasy points** for a points league.

- **Data:** 26,651 player-games from the 2025-26 season, pulled with `nba_api`
- **Approach:** one model per stat (points, rebounds, assists, steals …), comparing Linear, Ridge, Random Forest and Gradient Boosting against a recent-average baseline
- **Status:** Version 1 done · combined fantasy-point forecast is next
